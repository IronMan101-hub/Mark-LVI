# GALAHAD — final feature-completion report

*Built on branch `claude/brave-einstein-r87vaz` of the existing MARK LVI repository. 22 plugins, 209 commands, ~9.7k lines of Python in `galahad/`,
a 13-section dashboard, 142 automated tests (all passing at the time of writing).*

## How to read the statuses
The build environment was **Linux with no Windows, no audio hardware, no display, no vendor credentials, and an outbound network allow-list that
blocked news sites and search engines.** So: everything that can be proven with real files, a real SQLite database, a real headless Chromium,
a real HTTP server and faithful fakes of vendor APIs **is** proven (see the test column). Everything that needs Windows, a microphone, or a live
third-party account is implemented, labelled, and listed in *"Verify on your PC"* below — I have not claimed it works because I could not see it work.

## Verify on your PC (things I could not execute)
1. `python -m galahad doctor` → then `python main.py`. Confirm the tray icon appears, closing the window hides it, tray → Quit exits.
2. 🛰 GALAHAD DASHBOARD button opens the dashboard. Plugins → every plugin should show a health state (red = fix with the hint shown).
3. Windows control: *"open Notepad"*, *"set volume to 30"*, *"minimise Chrome"*, *"lock the computer"*, and one **shutdown** to see the confirmation banner (then deny it).
4. `python -m galahad autostart on`, sign out/in, check it starts minimised. `autostart off` to undo.
5. Settings → AI: add a key, **Test connection**. Then ask the assistant something free-form.
6. Intelligence → Sources: confirm each news feed shows *ok*. Settings → Location, then Home weather.
7. Spotify / Gmail / Google Calendar / WhatsApp Cloud: follow the Setup box in each plugin, run `connect`, grant permissions.
8. Optional: install Tesseract for offline OCR; enable Screen capture only if you want Vision.

## Known limitations (also in docs/)
* Plugins are not OS-sandboxed (see ARCHITECTURE). User plugins load only after you trust the exact file.
* "Install" in the Plugins page re-enables bundled plugins; there is no remote plugin store and no self-update channel.
* No dashboard translation; no multi-user/remote access (deliberately loopback-only).
* WhatsApp/Instagram read access and personal-account sending are impossible through permitted interfaces; marked accordingly.
* Calendar sync is one-way local→Google on create; Google events are read-only in the dashboard.
* Office automation uses document libraries, not Word/Excel/PowerPoint COM; edits to files currently open in Office may be refused by Windows.
* The 9 voice tools add ~20 k characters of tool description. If a small local model struggles, trim `bridge.GROUPS` or use the dashboard.
